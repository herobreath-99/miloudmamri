# Remix of PinkCare: Your Daily Wellness Guide

قم بالمهام التالية بالترتيب : باستخدام الصور و الملفات المرفقة قم ببناء التطبيق التالي : بما أن البيئة هي Lovable فمن الأفضل إعطاءه برومت/مواصفات هندسية كاملة، لأن Lovable يبني المشروع والواجهات والوظائف من الوصف ثم يولّد الكود تلقائيًا. هذا برومت احترافي جاهز للصق مباشرة داخل Lovable لإنشاء التطبيق بالكامل:

أنشئ تطبيق هاتف ذكي كامل باسم "PinkCare – دليلك اليومي لتكوني بأفضل حال" مخصص لمريضات سرطان الثدي بهدف مساعدتهن في الالتزام بالعادات الصحية اليومية والتذكير بالأنشطة المهمة ومتابعة الحالة الصحية.

التطبيق يجب أن يكون كاملاً وحديثًا مع واجهات احترافية وعصرية ثلاثية الأبعاد.

التصميم:

طابع أنثوي راقٍ وهادئ.

استخدم ألوان: الوردي الناعم، Rose Gold، الأبيض، البنفسجي الفاتح مع تدرجات جميلة.

أزرار ثلاثية الأبعاد مضيئة بتأثير Neon Glow.

بطاقات عائمة Glassmorphism.

حواف دائرية.

ظلال ناعمة.

أيقونات حديثة أنثوية.

رسوم متحركة ناعمة.

واجهة احترافية تشبه تطبيقات الصحة الحديثة.
